# Souq Al-Kul E-Commerce Platform

A multi-role retail and operational software platform supporting super admins, vendors, staff, moderators, and customers with bilingual support (Arabic and English).

## Features
- Multi-role portals and dashboards
- Secure authentication and role-based access control
- Responsive UI with Tailwind CSS
- Express backend and Vite frontend

## Development Setup
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm start
```
