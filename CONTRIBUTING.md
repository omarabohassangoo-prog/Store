# Contributing to Souq Al-Kul (سوق الكل)

We welcome contributions from developers and engineers to help improve Souq Al-Kul! Please follow these guidelines:

1. **Fork the Repository** and create your feature branch from `main`.
2. **Follow Coding Standards:**
   - Use TypeScript and modular ES modules.
   - Maintain bilingual support (Arabic & English) for UI strings.
   - Ensure secure coding practices (input validation, escape HTML).
3. **Run Tests & Linter:**
   ```bash
   npm run lint
   npm run build
   ```
4. **Submit a Pull Request** with a clear description of changes.
